# Screenshots

Save your own screenshots in this folder. Recommended names:

1. `01-wazuh-dashboard.png` — Wazuh dashboard overview
2. `02-wazuh-services.png` — VM1 service status
3. `03-agent-connected.png` — `ubuntu-endpoint-01` shown as Active
4. `04-ssh-detection.png` — expanded SSH event details

Capture readable screenshots with Windows + Shift + S, then save them here. Review each image before publishing. Remove credentials, tokens, personal information, and any details you do not want public.
